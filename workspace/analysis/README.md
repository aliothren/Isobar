# analysis: records, exports, figures

What the scripts produce, and the documents that carry the results. Every table, JSON file and figure is regenerated by a script. [`../../docs/02_final_pipeline.md`](../../docs/02_final_pipeline.md) names the script for each.

## The final results

| document / folder | content |
|---|---|
| [`SUMMARY.en.md`](SUMMARY.en.md) | the account of the framework and its results, in the paper's final state |
| [`paper_numbers.md`](paper_numbers.md) | every number of the paper with workload, configuration, denominator, statistic and source file |
| `v4/` (→ `/data/yuxinr/cimloop/analysis_v4`) | the deployment records, one directory per unit (`configs.jsonl` + summary tables), and the per-operator accounts (`v4/accounts/`, `v4/models/model_end_costs.json`) |
| `scale_2p7b_per_op.json` | the 2.7B-class reference account |
| `contention_system.json`, `soft_lever.json`, `search_withindie.json` | the intra-die instance of Fig. 1(a), its lever table and its exhaustive search |
| `simba_t1.json` | the Simba seating reference |
| `v3/e3_offload/`, `v3/e3_k2/` | the BookSim candidate libraries (Figs. 3(b), 4) |
| `v6/`, `v7/` | the tables behind every figure and table; `v7/plot_data_dictionary.md` describes the columns and `v7/plot_data_summary.md` the values |
| [`figures_dac2027/`](figures_dac2027/README.md) | the figure sets; `20261019_v3/` is final |
| `../gpu_comparison/` | the full-request energy comparison with GPUs (Table III): `REPORT_gpu_comparison.md`, `AUDIT_energy.md` |

## Earlier stages

The other documents and files here record earlier stages of the work. They include:

- the single-model main configuration of the 2.7B-class model: `main_config_results.md`, `mechanism_table.md`, `energy_export.md`, `METRICS.md`;
- the reference registry `ANCHORS.md` and the search specification `SEARCH_SPEC.en.md`;
- the chronological record `FIXLIST.en.md`.

Their numbers belong to those stages; the paper's numbers are the ones above.
