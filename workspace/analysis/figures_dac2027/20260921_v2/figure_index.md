## Notes for the author (not for the paper)

- Fig. 3(b): the source JSON records rho = 0.962 from ordinal ranks; two candidates tie on the analytic cost, and the standard Spearman with average ranks over the same 13 candidates is the value printed (see `data/fig3_booksim_rho.json`). The 154,037 packets are the size of ONE candidate's batch, not a total.
- Fig. 5(a-c) is a new controlled instance: the 25 flows are the real ffn1->ffn2 hand-off of the 2.7B mapping, re-placed on a 4x4 mesh and re-scored by the evaluator's own flow and load code. Its numbers are hand-off service costs on that instance and are not the 24x24 stage readings of v1 (26.2 / 21.0 / 13.1 ms), which belong to the 544-die layouts.
- Fig. 5(d) keeps the recorded denominator (the best resource-aware endpoint); the +11.4% / +11.2% labels are each proxy's best endpoint, the other seeds are drawn as points.
- Fig. 6(b): every cell uses the same statistic, recomputed from the per-run records; the sensitivity table in main_config_results.md mixes best-of-nine values and is not the source here.
- Only the PDFs, the data, the captions and this index are committed; SVG and PNG come back from the command in the header.
