# figures_dac2027: the paper figure sets

Each run directory is one complete set of candidate figures, generated by
one script into that directory only; a later set never overwrites an
earlier one.

| run | generator | status |
|---|---|---|
| `20260921_v2/` | `scripts/plot_dac2027_v2.py --run-id 20260921_v2` | current: the set the paper draft uses |
| `20260918_v1/` | `scripts/plot_dac2027_v1.py --run-id 20260918_v1` | superseded by v2 after the review of 2026-09-19; kept for comparison |

Inside a run: `composites/` holds the six figures as PDF and SVG, `panels/`
every standalone panel, `data/` the CSV and JSON behind each panel,
`captions.md` the formal captions, `figure_index.md` the per-figure record
(paper section, claim, instance, layout identifiers, statistic and
denominator, sources) with the author's notes, and `manifest.json` the
product list with a checksum inventory of the pre-existing figures at
generation time. PNG previews and SVG files are regenerated by the command
above and are not all committed.

The six figures of v2: (1) the placement phase diagram, (2) the platform
and a two-flow contrast, (3) the external references, (4) the deployment
gain and its dynamic energy, (5) the mechanism on a controlled 4x4 instance
with the objective ablation, (6) the bandwidth, port-capacity and geometry
conditions.
