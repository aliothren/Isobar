# figures_dac2027: the paper figure sets

Each run directory is one complete figure set, generated by one script into that directory only. `20261019_v3/` is the final set: the paper's seven figures come from it.

| run | generator | status |
|---|---|---|
| `20261019_v3/` | `scripts/plot_dac2027_v3.py --run-id 20261019_v3` (from the `v6/` and `v7/` exports) | final |
| `20260921_v2/` | `scripts/plot_dac2027_v2.py --run-id 20260921_v2` | earlier figure set (single-model main configuration) |
| `20260918_v1/` | `scripts/plot_dac2027_v1.py --run-id 20260918_v1` | earlier figure set |

## The paper's figures in `20261019_v3/composites/`

| paper | file | content |
|---|---|---|
| Fig. 1 | `fig1_phase_diagram.pdf` | intra-die and package phase diagrams with the boundary envelopes and projected designs |
| Fig. 2 | `fig2_platform.pdf` | the framework workflow and the communication model on an example hand-off |
| Fig. 3 | `fig3_validation.pdf` | silicon reference, BookSim validation, evaluation cost, search progress |
| Fig. 4 | `fig4_discrimination.pdf` | equal word-hops with unequal load; BookSim quality of the selected mappings |
| Fig. 5 | `fig5_gemma_result_stack.pdf` | Gemma-7B: latency of all layouts, latency and energy, savings by hand-off, bandwidth equivalent |
| Fig. 6 | `fig6_ninecell_row.pdf` | communication speed-ups of four models in three configurations |
| Fig. 7 | `fig7_mechanisms.pdf` | CIM capacity, resource organisation, bandwidth response, context length |

The other composites (`fig4_discrimination_alt`, `fig5_gemma_result`, `fig6_ninecell`) are layout alternatives of the same data. Inside the run, `panels/` holds the standalone panels, `data/` the CSV behind each panel, `meta/` each figure's metadata (sources, statistics, layout identifiers), `preview/` PNG renders, and `manifest.json` the product list.
