# Sources of the GPU baselines

## A_opt13b_a100 (CXL-PNM, HPCA 2024)

Paper: *An LPDDR-based CXL-PNM Platform for TCO-efficient Inference of Transformer-based Large Language Models*, HPCA 2024, pp. 970-982, DOI 10.1109/HPCA57654.2024.00078 (IEEE Xplore document 10476443). Values used: single A100 40 GB, FasterTransformer, OPT-13B, 64 input : 1024 output tokens; output throughput 47.33 tokens/s (Fig. 10 reading, section VIII-A); GPU power 253 W (text). Derived: T = 1024 / 47.33 = 21.635 s, E = 253 W x T = 5473.74 J, 5.345 J per output token (0.19 token/J in the figure). The throughput counts prefill and generation; the denominator is the 1024 output tokens. GPU dtype and beam are not stated for this point (the PNM side is described as FP16; recorded separately). Verified against the paper PDF (2026-10-21): section VII (p. 978) -- DGX A100 GPUs with 40 GB and 1.55 TB/s, FasterTransformer, OPT-13B on a single device, 64 input and up to 1024 output tokens; section VIII-A (p. 979) -- '253 Watts vs. 77.1 Watts' for 1024 output tokens with OPT-13B, CXL-PNM 10.8% lower throughput and 2.9x higher energy efficiency; Fig. 10 (p. 980) -- GPU bar 47.33 tokens/s and 0.19 token/J at [64:1024] (CXL-PNM 42.68 and 0.55). Values are tagged `figure reading` / `reported in text` / `derived` in `gpu_baselines.csv`.

## B_gemma7b_thor (Hydra, IISWC 2026)

Paper: *Hydra: Phase-Aware Workload Characterization of LLM Inference across Edge SoC Generations, Backends, and Quantization Levels*, arXiv:2608.25053. Data: github.com/amirtaherin/hydra at commit `1879bf8aff86ff8ed5388b245a351ff20a785f38` (cloned 2026-10-21 into `data/hydra`, this directory's `data` symlink -> /data/yuxinr/cimloop/gpu_comparison_sources). `data/unified/hydra_unified.tar.xz.part00/01` (sha256 4cb50177... / 26a4f22b..., matching the repository's SHA256SUMS) concatenated and extracted to `data/hydra_unified/`. File used: `media/amir/data/hydra-results/thor/results_llamacpp_thor/UNIFIED_gemma-7B_Q8_0_.csv`, sha256 `c9139dd8d288b929403f2a667484d58b6048495384cb80d4a8743a96df2df822`, 541 rows.

Recomputed from the raw fields (`scripts/gpu_baselines.py`): input lengths 13-345 tokens, mean 47.329, 84 distinct values (`hydra_input_lengths.csv`); every request 500 output tokens (`llama_n_eval` 499 subsequent forwards after the prompt evaluation, i.e. the first token reuses the prefill logits); mean `end_to_end_latency` 24.82638 s; mean `prefill_time + total_generation_time` 24.82547 s; mean board energy `vin_cur_prompt_mean / 1000 x end_to_end_latency` = 1898.68484 J (3.79737 J per output token); mean GPU-rail energy (`vdd_gpu_cur_prompt_mean`) 794.69908 J, a component of the board energy, kept as a diagnostic only. Per-request values in `hydra_requests.csv`. Energy = the author's mean power record x request time.
