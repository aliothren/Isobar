# tutorials: CiMLoop's notebooks

These are CiMLoop's tutorials, kept as upstream provides them: an
introduction to a CIM macro, editing variables, and components and reuse,
plus the speed and accuracy demonstration against NeuroSim. They teach the
lower layer this work builds on; nothing in them is specific to the
placement-aware overlay. `glossary_definitions.md` is CiMLoop's glossary.
NeuroSim is an external dependency and is not committed; see
[`../../EXTERNAL_DEPENDENCIES.md`](../../EXTERNAL_DEPENDENCIES.md).
